# Tom Ahn website

Start with INSTALL.txt. Upload the contents of this folder to the top level of your existing GitHub repository, keeping the existing PDFs, sheets and supplementary pages in place.

Publication records: dist/content.json. Each section has an items list. After the one-time GitHub Actions setup in INSTALL.txt, committing a data change rebuilds the page and updates its counts automatically. See UPDATING.md for record fields and ordering.
